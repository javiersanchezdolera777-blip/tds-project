# Gestión de Gastos

Proyecto de la asignatura Tecnologías de Desarrollo de Software (curso 2026/27), Universidad de Murcia.

Aplicación de escritorio para registrar y controlar gastos personales: categorías, filtros, gráficos, alertas de límite de gasto, cuentas compartidas con otras personas e importación de gastos desde ficheros del banco. También tiene una línea de comandos para dar de alta, modificar y borrar gastos.

## Requisitos

- Java 21
- Maven

## Cómo ejecutarlo

Desde la carpeta del proyecto:

    mvn javafx:run

Desde Eclipse: importar como *Existing Maven Project* y ejecutar *Run As > Maven build* con el goal `javafx:run`.
